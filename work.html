01 / open-source interface system

Morass

Live showcase → GitHub →
MORASS / PRODUCT INTERFACES
Workbench Overview Activity Settings
SYSTEM STATUS Everything has a place.

Typed structure, accessible states, and product-owned character.

The problem

Effigy products needed shared interface structure without becoming identical. Repeating app shells, forms, status language, focus behavior, and theme work in every product was slow and easy to get subtly wrong.

The approach

Morass provides interface primitives and documented contracts. Products keep their domain language and visual identity while sharing behavior, tokens, layouts, and release tooling.

The idea

Awards predictions usually collapse two different judgments: what someone believes will win and what they hope will win. Effigy Awards preserves both, then turns the gap into a better ballot, leaderboard, and conversation.

What is real

The React application supports shows, prediction workspaces, personal ballots, leaderboards, and an operator workflow. Current work is focused on identity, data preservation, and a guarded standalone release.
