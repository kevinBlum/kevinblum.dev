# kevinblum.dev

The public source for [kevinblum.dev](https://kevinblum.dev), Kevin Blum’s
personal website and photography archive.

## Local development

```sh
npm ci
npm run dev
```

The development server runs at `http://localhost:8000`.

To build and validate the production site:

```sh
npm run build
```

## Repository scope

This repository intentionally contains only the public website source and
display-ready photographs. Deployment infrastructure, private archive
material, and historical personal documents remain in a private repository.

Photography and writing are © Kevin Blum. No permission to reuse them is
granted by the publication of this source repository.
